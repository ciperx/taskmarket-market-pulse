What this dashboard measures

Public endpoints

This page fetches public Taskmarket API endpoints on load and every 60 seconds. No private data, no credentials.

  • GET /api/market/stats?chainId={id} — registered/active workers, open tasks, paid workers, active wallets.
  • GET /api/stats/breakdowns?chainId={id} — status, mode, reward and agent-count distributions.
  • GET /api/stats/platform-time-series?chainId={id}&range={7d|30d|90d|all}&bucket=day|week — created/completed tasks, reward and paid volume.
  • GET /api/stats/activity-heatmap?chainId={id}&range=30d&dimension=mode|hourOfWeek — mode/week-hour activity.
  • GET /api/stats/activity-feed?chainId={id}&limit=24 — recent public activity.
  • GET /api/tasks?chainId={id}&sort=newest&limit=100&cursor=... — newest task scan (12 pages/chain) for poster concentration, dead-task share, zero-submission open tasks, and top posters.

Honest scope: as of generation, stats/breakdowns/time-series/heatmap/feed return identical global aggregates across chainId. The page keeps chain selection, but labels those metrics Global. Chain-lens cards are computed from the selected chain’s task feed and are explicitly labeled.

Data snapshot in ./data/data.json is refreshed by node scripts/build.mjs; the live page also fetches the API directly in-browser for 60s updates.
